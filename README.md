## Правила репозитория

- Ключи API и личные данные клиентов в репозиторий не попадают никогда. Ключи — только в переменных окружения или файле `.env` (он в `.gitignore`).
- Каждый замер хранится вместе с конфигурацией, датой, версиями, сырыми результатами и скриптом, которым его можно повторить.
