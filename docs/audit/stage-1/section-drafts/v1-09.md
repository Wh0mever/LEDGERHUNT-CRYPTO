## 9. Веб-интерфейс и интерактивная визуализация графа

**Решение.** Интерфейс — статическая SPA на Vite 8.3 + React 19.3 + TypeScript с shadcn/ui и TanStack Router / Query / Table / Virtual (принято). Карта движения средств — Cytoscape.js 3.34.3 на canvas за собственным адаптером GraphView; число одновременно видимых элементов жёстко ограничено серверной агрегацией (ориентир аудита 1 500 узлов / 3 000 рёбер, не измерен); раскладка считается вне UI-потока и хранится в снимке расследования. Выбор рендерера и движка раскладки условный: до разработки адаптера обязателен benchmark-spike Этапа 2.

### Почему выбрано
- Cytoscape.js проверен через GitHub API и npm registry: MIT, релиз v3.34.3 от 2026-09-07, 7 релизов за 2026 год, типы TypeScript в пакете. В ядре: направленный мультиграф с разведением параллельных рёбер, подписи рёбер, compound-узлы, стили и фильтры по данным, layout preset.
- Лимит видимых элементов выбран вместо WebGL-режима: в типах 3.34.3 режим назван experimental, в основной документации не описан, рисует только треугольные стрелки и имеет открытую проблему с compound-узлами (issue #3376, с 2025-05). Приёмка на WebGL не опирается.
- Раскладка слева направо: слой узла равен номеру хопа, поэтому послойный расчёт линейный и воспроизводимый. Измеренные готовые движки медленны для интерактива: dagre — 2,34 с на 671 узел (PR #481, после оптимизации 2025 года), ELK layered — около 4 с на 406 узлов / 2 301 ребро (issue #372). Graphviz dot не измерен, сравнивается в spike.
- SPA без SSR: продукт — закрытый кабинет, в продакшене нет Node-процесса. По GitHub API у Next.js за 2026 год 41 security advisory (3 critical, 14 high), у Vite — 7, все про dev-сервер.
- shadcn/ui и TanStack: компоненты копируются в репозиторий без runtime-зависимости от поставщика; в реестре shadcn есть таблицы на TanStack Table 9, графики на Recharts 3, command palette и resizable-панели.
- Таймлайн не вводит вторую граф-библиотеку: режим «ось времени» на том же Cytoscape (preset, x = время) и гистограмма с выделением диапазона на Recharts 3.
- Готовый открытый UI расследований не переиспользуется: зрелых компонентов для TRON поиск по GitHub не нашёл; GraphSense Dashboard, crypttrace и bitquery/widgets — только UX-референсы.

### Лицензия и коммерческое использование
Cytoscape.js, cytoscape-dagre, cytoscape-fcose, Vite, React, shadcn/ui, Tailwind CSS, TanStack Query / Table / Virtual и Recharts — MIT; использование в закрытом коммерческом SaaS разрешено без условий. Лицензии TanStack Router и zustand (стор состояния графа) в аудите не зафиксированы — не проверено. Graphviz (EPL-2.0): вызов отдельным процессом закрытый код не затрагивает, а включение WASM-сборки в бандл требует оценки юриста. В сборку не допускаются cytoscape-svg (GPL-3.0), пакеты @cosmograph/* (CC-BY-NC-4.0) и NVL.

### Состояние проекта и расхождения «заявлено — на деле»
- Cytoscape.js: 18 открытых issue, 6 CI workflows. 18,5 млн загрузок npm в неделю почти целиком транзитивные через Mermaid; показатель прямого использования — cytoscape-dagre, около 357 тыс. в неделю.
- «Запас по масштабу через WebGL» не подтверждён: режим экспериментальный спустя 21 месяц после preview, основной автор занят редизайном v4 (issue #3486, без сроков), который сломает API.
- Производительность: есть только предварительные цифры авторов (Chrome, M1) — около 1 200 узлов / 16 000 рёбер при примерно 20 FPS на canvas. Независимых бенчмарков нет, сторонний код в аудите не запускался — не измерено.
- Расширения слабее ядра: react-cytoscapejs без релизов с 2022-09; cytoscape-fcose — с 2023-01-17, по умолчанию randomize: true и без seed, поэтому силовой вид воспроизводим только при сохранении позиций.
- Эталонный реестр shadcn собран на Next 16.3.8 — часть блоков придётся адаптировать под Vite; TanStack Table 9 — свежий мажор.
- Dev-машина работает на Node 23.4.0 (EOL с 2025-06-01); Node 24 уходит в Maintenance 2026-10-20, Node 26 становится Active LTS 2026-10-28.

### Инфраструктура и затраты
- Постоянные затраты: $0 в месяц. Статическую сборку раздаёт обратный прокси на уже имеющемся сервере, Node-процесса в продакшене нет; сборка — в Docker на Node 24.
- Переменные затраты на расследование: $0 — отрисовка идёт в браузере, платных запросов эта область не делает.
- Трудозатраты (оценка аудита): адаптер, стили и взаимодействия — 2–3 недели одного разработчика; послойная раскладка — около 1 недели; ось времени и связка гистограммы с фильтром — около 1 недели. Верификатор отдельно оценивает раскрытие ветвей, агрегацию рёбер, раскладку и SVG-экспорт в 3–4 недели собственного кода — это шире принципа «свой код — только клей».
- Компонентов, бесплатных только для разработки, нет. Все цены в таблице выше прочитаны 2026-10-13/14.

### Ограничения и риски
- Плавная работа на 1 000–10 000 узлов для выбранной библиотеки не доказана; без spike выбор остаётся гипотезой.
- Экран и отчёт рисуют разные рендереры: карту — Cytoscape, картинку для PDF — сервер (раздел 12). Совпадать должны данные общего снимка (узлы, рёбра, позиции) и простое подмножество стилей (сплошные линии, треугольные стрелки), а не пиксели. Аудит исходил из PNG через cy.png() и headless-браузера на сервере; серверный рендер графа без браузера в нём не измерен.
- Простая послойная раскладка даёт больше пересечений рёбер, чем ELK; веера в сотни адресов на хоп сворачиваются в мета-узлы «ещё N».
- Sigma 4.0.x в ближайшие месяцы не готовая страховка, а коммерческий запасной путь дорог и непрозрачен по ценам.
- cy.png({full: true}) создаёт canvas размером с весь граф; предельные размеры canvas в браузере не проверены — экспорт с экрана только из свёрнутой карты с maxWidth / maxHeight.

### Как проверяем качество
- Круговая сверка: cy.json() после загрузки сравнивается с JSON API — у каждого ребра непустой TXID, сумма и время совпадают с бэкендом (цель «100% фактов с TXID»).
- Benchmark-стенд на Playwright: синтетические графы 1 000 / 5 000 / 10 000 узлов; время до первого кадра, FPS при pan / zoom, время раскладки.
- Property-тесты раскладки: детерминизм, отсутствие наложений узлов, монотонность x по номеру хопа, корректная обработка циклов.
- Скриншотные регрессионные тесты на эталонных сценариях из набора 50+; число узлов и рёбер на картинке равно числу в JSON-отчёте; автотест на пустое изображение.
- Тест меток: бейдж строится только из label.source и confidence, неизвестный адрес не получает биржевой бейдж.
- CI: tsc --noEmit, линтер, Vitest, e2e на Playwright, npm audit, проверка, что ключи API не попадают в бандл и логи.

### Заменяемость
Рендерер графа — средняя: библиотека изолирована за интерфейсом GraphView (load, applyFilter, highlightPath, expand, export), модель графа нейтральная, типы генерируются из OpenAPI. Переход на Sigma — переписывание одного адаптера, по оценке аудита 1–2 недели; для коммерческого SDK оценки нет. Раскладка — высокая: чистая функция «граф → координаты». Фреймворк и UI-кит — высокая: обычные React-компоненты.

### Что проверить до фиксации выбора (Этап 2)
1. Benchmark-spike (2–3 дня, блокирующий): Cytoscape на canvas, графы 1 000 / 5 000 / 10 000 узлов с compound-узлами и подписями рёбер, ноутбук со встроенной графикой. Ориентир аудита (пороги и целевое железо утверждают владельцы): не менее 30 FPS на 1 000 узлов с подписями и рабочее взаимодействие на лимите 1 500 узлов / 3 000 рёбер.
2. В том же spike — Sigma 4.0.x как обзорный рендерер на 10 000 узлов. Ориентир «не менее 15 FPS» аудит задавал для WebGL-режима Cytoscape; порог для Sigma утверждают владельцы.
3. Сравнение раскладок: собственный послойный алгоритм, Graphviz dot (нативно на бэкенде и WASM в Web Worker) и dagre на 1 000 и 10 000 узлов. Критерий: одинаковый вход даёт одинаковые координаты; порог времени в аудите не задан, его утверждают владельцы.
4. Серверная картинка отчёта без headless Chromium (Graphviz dot → SVG, ECharts SSR): повторный запуск даёт идентичный файл, число элементов совпадает с JSON, подписи читаемы при печати. Там же — сравнение ECharts и Recharts для гистограммы времени.
5. `shadcn init` для шаблона Vite с закреплёнными версиями; Node 24 в Dockerfile и .nvmrc, переход на Node 26 LTS после 2026-10-28.
