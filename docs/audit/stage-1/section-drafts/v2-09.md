## 9. Веб-интерфейс и интерактивная визуализация графа

**Решение.** Интерфейс — статическое одностраничное приложение (SPA) на Vite 8.3, React 19.3 и TypeScript с набором компонентов shadcn/ui и библиотеками TanStack Router / Query / Table / Virtual (принято). Карта движения средств — Cytoscape.js 3.34.3 на canvas за собственным адаптером GraphView; число одновременно видимых элементов жёстко ограничено серверной агрегацией (ориентир перепроверки — 1 500 узлов и 3 000 рёбер, не измерен); раскладка считается вне потока интерфейса и хранится в снимке расследования. Картинку графа для PDF рисует сервер из того же снимка (G10). Выбор библиотеки карты и движка раскладки условный: до разработки адаптера обязательна проверочная реализация с замерами (spike) на Этапе 2.

### Почему выбрано
- Cytoscape.js проверена через GitHub API и реестр npm: MIT, релиз v3.34.3 от 2026-09-07, 7 релизов за 2026 год, типы TypeScript в пакете. В ядре: направленный мультиграф с разведением параллельных рёбер, подписи рёбер, составные узлы-группы (compound), стили и фильтры по данным, раскладка по готовым координатам (preset).
- Лимит видимых элементов выбран вместо режима WebGL (отрисовка на видеокарте; canvas — обычная двумерная отрисовка браузера): в типах версии 3.34.3 режим WebGL назван experimental, в основной документации не описан, рисует только треугольные стрелки и имеет открытую проблему с узлами-группами (issue #3376, с 2025-05). Приёмка на WebGL не опирается.
- Раскладка слева направо: слой узла равен номеру хопа (шага перевода от исходного адреса), поэтому послойный расчёт линейный и воспроизводимый. Готовые движки по опубликованным замерам медленны для интерактивной работы: dagre — 2.34 с на 671 узел (PR #481, после оптимизации 2025 года), ELK layered — около 4 с на 406 узлов и 2 301 ребро (issue #372). Graphviz dot не измерен, сравнивается на Этапе 2.
- SPA без серверной отрисовки страниц: продукт — закрытый кабинет, в production нет процесса Node. По GitHub API у Next.js за 2026 год 41 уведомление об уязвимостях (3 критического уровня, 14 высокого), у Vite — 7, все про сервер разработки.
- shadcn/ui и TanStack: компоненты копируются в репозиторий, зависимости от поставщика во время работы нет; в реестре shadcn есть таблицы на TanStack Table 9, графики на Recharts 3, палитра команд и панели с изменяемым размером.
- Шкала времени не вводит вторую графовую библиотеку: режим «ось времени» на том же Cytoscape (preset, x = время) и гистограмма с выделением диапазона на Recharts 3.
- Готовый открытый интерфейс расследований не переиспользуется: зрелых компонентов для TRON поиск по GitHub не нашёл; GraphSense Dashboard, crypttrace и bitquery/widgets — только образцы UX.

### Лицензия и коммерческое использование
Cytoscape.js, cytoscape-dagre, cytoscape-fcose, Vite, React, shadcn/ui, Tailwind CSS, TanStack Router / Query / Table / Virtual, zustand (состояние карты в браузере) и Recharts — MIT: использование в закрытом коммерческом SaaS разрешено; условие MIT — сохранять уведомление об авторских правах и текст лицензии. TypeScript — Apache-2.0. Лицензии Vite, React, TypeScript, TanStack Router и zustand сверены 2026-10-14 через GitHub API. Graphviz (EPL-2.0): по нашему прочтению, вызов отдельным процессом закрытый код не затрагивает, а включение WASM-сборки в сборку интерфейса требует оценки юриста. По нашему прочтению лицензий, в сборку не допускаются cytoscape-svg (GPL-3.0), пакеты @cosmograph/* (CC-BY-NC-4.0) и NVL.

### Состояние проекта и расхождения «заявлено — на деле»
- Cytoscape.js: 18 открытых issue, 6 CI workflows. 18.5 млн загрузок npm в неделю почти целиком транзитивные — через библиотеку диаграмм Mermaid; показатель прямого использования — cytoscape-dagre, около 357 тыс. в неделю.
- «Запас по масштабу через WebGL» из первичного исследования перепроверка не подтвердила; основной автор занят редизайном версии 4 (issue #3486, без сроков) — по нашей оценке, переход на неё потребует переделки адаптера.
- Производительность не измерена: есть только предварительные цифры авторов (Chrome, M1) — около 20 кадров в секунду на canvas при 1 200 узлах и 16 000 рёбер; независимых замеров не найдено, сторонний код не запускался.
- Расширения слабее ядра: обёртка react-cytoscapejs без релизов с 2022-09; силовая раскладка cytoscape-fcose — с 2023-01-17, по умолчанию randomize: true и без seed, поэтому силовой вид воспроизводим только при сохранении позиций.
- Эталонный реестр shadcn собран на Next 16.3.8 — часть блоков придётся адаптировать под Vite; TanStack Table 9 — свежая мажорная версия.
- На машине разработки стоит Node 23.4.0 (поддержка прекращена 2025-06-01); Node 24 переходит в Maintenance 2026-10-20, Node 26 становится Active LTS 2026-10-28.

### Инфраструктура и затраты
- Постоянные затраты: $0 в месяц. Статическую сборку раздаёт Caddy на общем сервере (G12), процесса Node в production нет; сборка — в Docker на Node 24.
- Переменные затраты на расследование: платных вызовов эта часть не делает. Карта рисуется в браузере; серверное время на агрегацию, раскладку и картинку для PDF измеряется по каждому расследованию (G17).
- Трудозатраты (оценки, не измерены). Первичное исследование: адаптер, стили и взаимодействия — 2–3 недели одного разработчика; послойная раскладка — около 1 недели; ось времени и связка гистограммы с фильтром — около 1 недели; итого 4–5 недель. Перепроверка отдельно оценивает раскрытие ветвей, агрегацию рёбер, раскладку и SVG-экспорт в 3–4 недели собственного кода. Это отступление от принципа «свой код — только клей» (см. пункт 10 в A2 и вопрос 1 в A7).
- Компонентов, бесплатных только для разработки, нет. Все цены в таблице выше прочитаны 2026-10-13/14.

### Ограничения и риски
- Плавная работа на 1 000–10 000 узлов для выбранной библиотеки не доказана; без проверки Этапа 2 выбор остаётся гипотезой. Требование закрывается свёрнутой картой в пределах лимита с раскрытием ветвей по запросу, а не показом всех узлов сразу; иное прочтение требования владельцами меняет решение.
- Экран и отчёт рисуют разные программы: карту — Cytoscape в браузере, картинку для PDF — сервер (G10, раздел 12). Совпадать должны данные общего снимка (узлы, рёбра, позиции) и простое подмножество стилей (сплошные линии, треугольные стрелки), а не пиксели. Серверная отрисовка графа без браузера не измерена.
- Простая послойная раскладка даёт больше пересечений рёбер, чем ELK; веера в сотни адресов на хоп сворачиваются в мета-узлы «ещё N».
- Sigma 4.0.x в ближайшие месяцы не готовая страховка, а коммерческий запасной путь дорог и непрозрачен по ценам.
- cy.png({full: true}) создаёт canvas размером с весь граф; предельные размеры canvas в браузере не проверены — экспорт с экрана только из свёрнутой карты с maxWidth / maxHeight.

### Как проверяем качество
- Круговая сверка: cy.json() после загрузки сравнивается с JSON API — у каждого ребра непустой TXID, сумма и время совпадают с бэкендом (цель «100% фактов с TXID»).
- Стенд замеров на Playwright (автотесты в браузере): синтетические графы на 1 000, 5 000 и 10 000 узлов; время до первого кадра, кадры в секунду при сдвиге и масштабировании, время раскладки. Это компонентный бюджет: приёмка скорости — один сквозной замер от старта задачи до проверенного JSON-отчёта в интерфейсе (раздел 13); картинка для PDF рисуется отдельной асинхронной задачей (G11) и в него не входит.
- Тесты свойств раскладки: детерминизм, отсутствие наложений узлов, монотонность x по номеру хопа, корректная обработка циклов.
- Скриншотные регрессионные тесты на сценариях из набора не менее 50 с известным правильным ответом; число узлов и рёбер на картинке равно числу в JSON-отчёте; автотест на пустое изображение.
- Тест меток: значок метки строится только из label.source и confidence, рядом показываются источник, дата проверки и достоверность; неизвестный адрес и эвристический «кандидат» (G7) значок биржи не получают.
- CI: tsc --noEmit, линтер, Vitest, сквозные тесты на Playwright, npm audit, проверка, что ключи API не попадают в сборку и логи.

### Заменяемость
Библиотека карты — средняя: она изолирована за интерфейсом GraphView (load, applyFilter, highlightPath, expand, export), модель графа нейтральная, типы генерируются из OpenAPI. Переход на Sigma — переписывание одного адаптера, по оценке первичного исследования 1–2 недели; для коммерческой библиотеки оценки нет. Раскладка — высокая: чистая функция «граф → координаты». Фреймворк и набор компонентов — высокая: обычные React-компоненты.

### Что проверить до фиксации выбора (Этап 2)
1. Проверочная реализация с замерами на стенде (2–3 дня, блокирует разработку адаптера): Cytoscape на canvas, графы с узлами-группами и подписями рёбер, ноутбук со встроенной графикой. Критерий по умолчанию (пороги и целевое оборудование вправе изменить владельцы): не менее 30 кадров в секунду на 1 000 узлов с подписями и работа без зависаний на лимите 1 500 узлов и 3 000 рёбер. При провале лимит снижается до уровня, где порог выполняется; если карта при этом нечитаема — запасной путь (Sigma либо GoJS или KeyLines) по решению владельцев.
2. В той же проверке — Sigma 4.0.x как обзорный вид на 10 000 узлов. Порог задают владельцы (ориентир первичного исследования для режима WebGL — не менее 15 кадров в секунду). При провале обзорного вида в MVP нет, остаётся свёрнутая карта.
3. Сравнение раскладок: собственный послойный алгоритм, Graphviz dot (нативно на сервере и WASM-сборка в фоновом потоке браузера) и dagre на 1 000 и 10 000 узлов. Критерий: одинаковый вход даёт одинаковые координаты; порог времени не задан, его задают владельцы. Если Graphviz dot проходит, собственный алгоритм не пишется.
4. Серверная картинка графа для отчёта без headless Chromium; кандидаты: Graphviz dot → SVG, собственная сборка SVG из позиций снимка, для диаграмм — ECharts с серверной отрисовкой SVG. Критерий: повторный запуск даёт идентичный файл, число элементов совпадает с JSON, подписи читаемы при печати. При провале — headless Chromium в составе Gotenberg, только по решению владельцев (G10). Там же — ECharts против Recharts для гистограммы времени.
5. `shadcn init` для шаблона Vite с закреплёнными версиями; Node 24 в Dockerfile и .nvmrc, переход на Node 26 LTS после 2026-10-28.
